# 매일 쇼츠 발행 자동화 (n8n)

`daily-short.json` 을 n8n 에서 **Import from File** 로 불러오면 워크플로가 만들어집니다.
자격증명은 전부 비어 있으니 아래 세 가지만 채우면 됩니다.

## 채워야 하는 것

| 노드 | 넣을 값 |
|---|---|
| 유튜브 업로드 | YouTube OAuth2 자격증명 |
| 텔레그램 알림 / 조용한 날 보고 | Telegram 자격증명과 운영자 `chatId` |
| 제목 다듬기 (선택) | OpenAI 자격증명 · 기본은 꺼져 있음 |

`설정` 노드의 경로 네 개(`repo`, `python`, `outputDir`, `privacyStatus`)도 이 PC 기준으로
들어가 있으니, 다른 곳에서 돌리면 바꿔 주세요.

## 도는 순서

1. **평일 아침 08:40** (워크플로 Timezone 을 `Asia/Seoul` 로 둬야 한국 시간이 맞습니다)
2. **오늘 뭘 만들지 고른다** — `shorts-plan --json`. 데이터가 스토리를 고릅니다.
3. **만들 이야기가 있나** — 발동한 스토리 중 렌더 가능한 게 없으면 텔레그램으로만 알리고 끝냅니다.
4. **영상 만들기** — `shorts --story <선택된 스토리>`. 내레이션을 먼저 만들어 길이를 재고,
   장면을 거기 맞춘 뒤 HyperFrames 로 찍고 음성을 입힙니다. 3~5분 걸립니다.
5. **유튜브 업로드** → **발행 기록 남기기** → **텔레그램 알림**

## 처음 돌릴 때

- `privacyStatus` 를 `private` 으로 두고 **수동 실행**으로 한 번 돌려 결과를 확인하세요.
- 유튜브 API 심사를 통과하기 전에는 API 로 올린 영상이 **비공개로 잠깁니다**.
  심사 신청은 먼저 해두고, 그동안은 `private` 으로 쌓아두거나 손으로 올리는 편이 낫습니다.
- **유튜브 업로드** 노드를 열어 바이너리 필드 이름이 `video` 인지 확인하세요.
  앞 노드가 그 이름으로 파일을 싣습니다. n8n 버전에 따라 항목 위치가 다를 수 있습니다.

## 이 PC 가 켜져 있어야 합니다

렌더는 로컬 GPU(헤드리스 크롬)와 로컬 VoxCPM 을 씁니다. n8n 이 `Execute Command` 로
이 저장소의 CLI 를 직접 부르므로, n8n 과 이 PC 가 같은 기계에 있어야 합니다.
다른 기계에서 돌리려면 렌더 단계를 원격 실행으로 바꿔야 합니다.

## 발행 기록

`shorts-out/published.json` 에 무엇을 언제 올렸는지 쌓입니다. 내일의 선택기가 이 파일을 보고
최근에 쓴 이야기를 피합니다. 지우면 같은 이야기가 연달아 나올 수 있습니다.
경로는 `TRADINGAGENTS_SHORTS_LEDGER` 로 바꿀 수 있습니다.

## 직접 확인해보기

```
tradingagents shorts-plan --table     # 오늘 무엇이 발동했는지, 점수와 함께
tradingagents shorts --story record   # 그 영상을 직접 만들어 보기
```
