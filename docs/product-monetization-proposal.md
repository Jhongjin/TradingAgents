# 월 1만원 구독 상품화 제안

작성일: 2026-09-09. 홈 리디자인(A+D)과 KIS 모의투자 자동화가 배포된 시점의 제안입니다.

## 0. 먼저 확인할 것: 규제

불특정 다수에게 **유료로 종목 매수·매도 의견을 제공**하면 자본시장법상 유사투자자문업
신고 대상이 됩니다(금융감독원 신고제, 2024년 요건 강화: 대표자 교육 이수, 손해배상
준비, 광고·환불 규정 등). 두 가지 길이 있습니다.

| 길 | 내용 | 장단점 |
|---|---|---|
| A. 유사투자자문업 신고 | "오늘의 종목·등급"을 그대로 유료 제공 | 상품이 단순하고 강함. 신고·교육·표시의무·환불규정 필요 |
| B. 리서치 도구(SaaS)로 포지셔닝 | 사용자가 **자기 관심종목**에 대해 하네스를 실행하고, 결과는 "분석 자료"로 표기 | 규제 부담 낮음. "추천"이 아니라 "도구"라는 선이 UI·카피에서 지켜져야 함 |

권장: **B로 시작해 트랙 레코드를 쌓고, 유료 전환 지표가 확인되면 A를 병행**합니다.
어느 쪽이든 실계좌 자동매매(투자일임)는 별도 인가 영역이므로 상품에 넣지 않습니다.
이 문서는 법률 자문이 아니며, 출시 전 전문가 검토가 필요합니다.

## 1. 상품 구조 (3단계)

| 플랜 | 가격 | 핵심 가치 | 포함 |
|---|---|---|---|
| 무료 | 0원 | 신뢰 쌓기·SEO | 홈(전일 호 헤드라인), 공개 사후 성과, 종목 페이지 기본 정보, 주 1회 이메일 요약 |
| **데일리 패스** | **월 10,000원** | "아침 8시에 오늘의 호가 도착한다" | 당일 하네스 실시간(07:50·10:05 실행 즉시), 토론 전문·근거 데이터, 관심종목 10개 분석 요청 월 20회, 텔레그램/카카오 알림, 내 가상계좌 자동 추적, 세 가지 테마·광고 제거 |
| 프로 | 월 30,000원 | "내 규칙으로 돌린다" | 사용자 지정 유니버스·리스크 파라미터로 하네스 실행, 본인 KIS 모의투자 키 연동(주문 초안은 사용자가 승인), 주간 PDF 리포트, JSON API |

1만원 플랜의 판매 문장은 하나입니다: **"매일 아침 AI 다섯이 토론해서 고른 종목과, 그
선택의 성적표를 받아 본다."** 이미 홈 첫 화면이 이 문장을 구현하고 있습니다.

## 2. 왜 1만원이 성립하는가 (원가)

- 하네스 실행(스크리닝·예측·토론)은 **구독자 수와 무관하게 하루 1~3회**만 돕니다.
  LLM 비용은 실행당 약 300~600원 수준이라 월 5만원 이내로 고정됩니다.
- 사용자별 비용은 "분석 요청"뿐입니다. 요청당 LLM 비용 약 300~500원이므로 월 20회
  상한이면 최대 1만원 근처까지 갈 수 있어, 실제 평균 사용량(3~5회)을 보고 상한을 조정합니다.
- 인프라(Vercel Pro + Supabase Pro) 약 6만원/월, 결제 수수료 3.5% 내외.
- 손익분기: 구독자 약 15~20명. 100명이면 월 약 80만원 마진.

## 3. 결제·계정

- 결제: 포트원(구 아임포트) 또는 토스페이먼츠 **정기결제(빌링키)**. 카카오페이·네이버페이
  포함. 해외 카드가 필요하면 Stripe를 병행하되 국내는 포트원이 전환율이 높습니다.
- 계정: 이미 Supabase Auth 회원 체계가 있으므로 `subscriptions` 테이블(플랜, 상태,
  만료일, 결제 고객키)과 결제 웹훅 라우트만 추가하면 됩니다.
- 접근 제어: `/api/harness/runs/latest`는 무료 사용자에게 **전일 실행**만, 유료
  사용자에게 당일 실행을 반환합니다(서버에서 플랜을 확인). 토론 전문(detail JSON)은
  유료 전용.
- 환불: 7일 내 전액 환불 규정 명시(유사투자자문업 신고 시 필수).

## 4. 습관을 만드는 알림

- 07:55 KST "제 N호 도착: 오늘은 ○○만 남았습니다" (텔레그램 봇이 가장 빠르게 구축됨,
  카카오 알림톡은 채널 심사 후 추가).
- 보유 종목 손절·익절 발동, 5D/20D 결과 확정 시 알림.
- 알림은 클릭 → 홈 '오늘의 하네스'로 연결되어 재방문을 만듭니다.

## 5. 획득 채널

- 종목 페이지 SEO: 이미 `/stocks/{code}`가 있으므로 KOSPI200·KOSDAQ150 전 종목
  페이지를 사이트맵에 넣고, 하네스 결정 이력을 종목 페이지에 노출합니다.
- **공개 성적표가 마케팅입니다.** 승률·알파를 숨기지 않고 매주 '주간 성적표' 글을
  블로그·커뮤니티(클리앙, 뽐뿌 주식, 블라인드)에 올립니다. 나쁜 주도 공개합니다.
- 14일 무료 체험 → 결제. 체험 중에도 당일 하네스를 열어 주고, 만료 후 전일로 내립니다.

## 6. 4주 실행 순서

1. **1주차**: 규제 방향 결정(A/B), 약관·환불 규정 초안, 포트원 가입·심사.
2. **2주차**: `subscriptions` 스키마·웹훅·플랜 게이트, 마이페이지에 결제 버튼, 무료/유료
   데이터 분리(당일 vs 전일).
3. **3주차**: 텔레그램 알림 봇, 관심종목 분석 요청 쿼터(플랜별), 체험 플로우.
4. **4주차**: 베타 100명 무료 초대(체험 30일) → 전환율·D7 재방문·알림 클릭률 측정 →
   가격·쿼터 확정.

## 7. 성공 지표

- 체험→유료 전환 8% 이상, 월 이탈 10% 이하.
- 알림 클릭률 30% 이상(습관 형성의 대리 지표).
- 공개 20일 알파가 양수로 유지될 것. 음수 구간에서는 신규 유입보다 투명성 커뮤니케이션을 우선.

## 8. 하지 말아야 할 것

- 실계좌 자동 주문 판매(투자일임업 인가 영역).
- "수익 보장", "적중률 ○○%" 식 광고(표시광고법·자본시장법 위반 소지).
- 무료 사용자에게 당일 종목을 그대로 노출(유료 가치 붕괴).
