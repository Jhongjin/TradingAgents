# 02 Design Experience

## Mandate

Make the product feel credible, clear, and useful for Korean investors. Design
should support decision context, not decorate uncertainty.

## Responsibilities

- public homepage and stock-page information architecture
- member dashboard usability
- mobile and desktop layout quality
- accessible controls, focus states, and reduced-motion support
- visible trust signals: data sources, timestamps, risk notices, read-only mode

## Design Principles

- Lead with real product value, not marketing abstraction.
- Use Korean investor language plainly.
- Keep dense data scannable with strong hierarchy.
- Let motion communicate live signal flow; avoid hiding content behind motion.
- Do not make dashboard surfaces look like landing-page cards.

## Verification

- desktop screenshot
- mobile screenshot at 390px and 320px when relevant
- console warning/error check
- horizontal overflow check
- reduced-motion behavior for animated hero surfaces
