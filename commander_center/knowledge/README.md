# Knowledge And Skill Acquisition

This folder tracks durable knowledge the Commander Center should reuse instead
of rediscovering. It is intentionally separate from code because source
interpretation, policy context, and domain vocabulary change over time.

## Knowledge Areas

- Korean market microstructure and terminology
- KRX Open API endpoint behavior
- DART disclosure and financial statement interpretation
- Naver news search quality and limitations
- benchmark alpha and realised outcome methodology
- AI report evaluation examples
- security/compliance launch lessons

## Rules

- Prefer official sources for market rules, tax, regulation, and API behavior.
- Record date checked for time-sensitive facts.
- Treat non-official articles as context, not authority.
- Do not store secrets or copied API keys here.
- When a fact could affect user trust or public claims, link the source and add
  a review cadence.
